Rejouer. Essayer. Comprendre.

Version 1.2.0 — Go, Python et PostgreSQL. Go fournit les ticks historiques ; Python gère le replay ; PostgreSQL conserve le marché et les exercices. Le premier démarrage importe les archives et peut prendre plusieurs minutes. Aucune connexion broker.

La vraie partie replay de PurpleChart, dans une application autonome. Explore les futures enregistrés, prends des positions simulées et retrouve tes exercices dans ton journal.

Ton premier exercice

  1. Choisis une séance, indique ton heure de départ en UTC, puis clique sur Charger.
  2. Utilise Lecture / Pause et une vitesse de 0,5× à 50×. Change de période sur le graphique et zoome pour examiner les bougies.
  3. Choisis ton risque et ton ratio, puis Achat ou Vente. Déplace les lignes SL/TP et confirme le ticket.
  4. Consulte le Journal et la Performance. Tu peux fermer partiellement, sortir entièrement ou enregistrer ta session.

Les outils disponibles

EMA20/50, VWAP Globex/RTH et bandes, profil de volume de séance, VP de mesure, tape, delta cumulé et volumes exécutés par niveau. Les niveaux gamma PW, CW et FL sont disponibles sur NQ/MNQ selon les snapshots conservés ; le symbole ≈ indique une projection historique sur le future.

Le catalogue des régimes est rétrospectif. Les cours et les niveaux utilisés pendant l’exercice restent bornés au curseur. Le DOM montre les volumes exécutés ; il ne représente pas un carnet d’ordres complet.

Comprendre ton compte

Sans position ouverte, le montant principal est le solde après trades clôturés et frais. Avec une position, la valeur estimée du compte ajoute son gain ou sa perte provisoire ; le détail apparaît dessous. Les frais déjà comptabilisés ne sont pas déduits une seconde fois.

Un espace à toi

Le navigateur conserve un cookie pour retrouver ton compte simulé et ton journal. Chaque navigateur a son propre espace. Aucun journal personnel de l’auteur n’est fourni. Les indicateurs et stratégies privés sont exclus de cette édition.

Données incluses

L’inventaire des enregistrements est disponible dans le paquet Docker.

Ce sont des enregistrements historiques, avec leurs périodes de couverture et leurs éventuelles interruptions. Aucun flux live n’est nécessaire.

Organisation du code et revue des dépendances

Installer avec Docker

Télécharge et extrais le paquet, puis lance cette commande dans son dossier :

docker compose up -d --build

Ouvre ensuite http://127.0.0.1:8948/. Les données sont incluses et montées en lecture seule ; tes journaux restent dans un volume Docker distinct.

docker compose stop
docker compose start
