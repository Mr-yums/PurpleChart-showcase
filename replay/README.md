# Module Purple Replay

`backend/app` contient l’API FastAPI, le moteur de replay, les ordres simulés et le journal. `frontend` contient le workspace et ses composants Svelte. Le frontend autonome et le déploiement Docker sont décrits dans le README à la racine du projet.

Le module utilise exclusivement les copies historiques fournies dans `data/`. Les signaux propriétaires, les connexions au live et les données personnelles sont exclus de la distribution.
